# PkpTab

An accessible tab component for organizing content into switchable panels.

<Primary />
<Controls />

## HTML Structure

```html
<div class="PkpTabRoot">
	<!-- Tab buttons -->
	<div class="PkpTabList">
		<button class="PkpTabTrigger" data-state="active">Abstract</button>
		<button class="PkpTabTrigger" data-state="inactive">Details</button>
		<button class="PkpTabTrigger" data-state="inactive">References</button>
	</div>

	<!-- Tab content panels -->
	<div class="PkpTabContent" data-state="active">Abstract content here...</div>
	<div class="PkpTabContent" data-state="inactive">Details content here...</div>
	<div class="PkpTabContent" data-state="inactive">
		References content here...
	</div>
</div>
```

## External Triggers

You can trigger a tab from any element external to the tabs component by firing a `pkp.opentab` event on the global `window`.

```
<PkpTabRoot v-bind="{name: example, ...}">
	<PkpTabList>
		<PkpTabTrigger value="overview">Overview</PkpTabTrigger>
		<PkpTabTrigger value="files">Files</PkpTabTrigger>
	</PkpTabList>
	<PkpTabContent value="overview">
		<p>Overview content.</p>
	</PkpTabContent>
	<PkpTabContent value="files">
		<p>Files content.</p>
	</PkpTabContent>
</PkpTabRoot>
<button onClick="window.dispatchEvent(new CustomEvent('pkp.opentab', {details: {group: 'example', tab: 'files'}}))">
	Open Files
</button>
```
