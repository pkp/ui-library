# useScrollTo

`useScrollTo` scrolls an element to the top of the window, or of a scrolling container, using the browser's own scrolling. Whether the scroll animates is decided by the stylesheet (`scroll-behavior` in `_global.less`, which switches to an instant jump under `prefers-reduced-motion: reduce`), so callers never choose an animation themselves.

## Examples

### Bring the top of a component back into view

```js
const {scrollTo} = useScrollTo();
scrollTo(this.$el, {offset: -50});
```

### Scroll inside a side modal instead of the page

```js
const {scrollTo} = useScrollTo();
const container = document.querySelector('div.pkp-modal-scroll-container');
scrollTo(fieldElement, {offset: -50, container});
```

`target` accepts a selector, an element or a component instance. `offset` is added to the final position, so a negative value leaves room above the element (for a sticky header).
